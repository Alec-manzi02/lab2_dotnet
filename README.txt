LAB 2 - WINDOWS FORMS APPLICATION

How to open:
1. Extract the Lab2_WinForms.zip file.
2. Open the extracted Lab2_WinForms folder.
3. Double-click Lab2.sln.
4. In Visual Studio, wait for the project to load.
5. Press F5 or click Start to run.

Project target:
.NET Framework 4.8

The project includes four ready-made Windows Forms:
- LoginForm
- ChooseForm
- BicycleForm
- MushroomForm

The Login form checks that both fields are not empty. Any non-empty username and password are accepted.

If Visual Studio asks to install or target .NET Framework 4.8 developer tools, follow its prompt or retarget the project to an installed .NET Framework version.

No comments are included in the C# source code.
